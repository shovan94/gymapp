# GymApp — Personal Workout & Protein Tracker

A mobile-first personal gym app built with React + Vite + Tailwind CSS, tailored to a 5-day wedding-prep training split.

## Features

- **Dashboard** — Today's workout card, animated protein ring, streak counter, week-at-a-glance strip
- **Schedule** — Full 7-day week view with workout/recovery/rest types and set progress
- **Workout Logger** — Per-set weight + rep logging with form tips and session progress bar
- **Protein Tracker** — 180g daily goal ring, quick-add buttons, custom entries, meal plan guide
- **Progress** — 7-day protein bar chart, per-exercise strength history with trend indicators

All data persisted to `localStorage` — no backend required.

## Getting Started

```bash
npm install
npm run dev
```

## Stack

- React 19 + Vite 8
- Tailwind CSS 3
- Lucide React icons
- localStorage for persistence
